# Лабораторная работа №2: Алгоритмы сортировки и анализ трафика

Проект реализует и сравнивает алгоритмы сортировки на языке Python для двух практических сценариев:
1. Каталог товаров маркетплейса (сравнение квадратичных и логарифмических алгоритмов).
2. Анализ сетевых логов для выявления DDoS-атак (линейные некомпараторные алгоритмы).

## Реализованные алгоритмы

* **Bubble Sort (Пузырьком)** — $O(n^2)$
* **Selection Sort (Выбором)** — $O(n^2)$
* **Quick Sort (Быстрая сортировка)** — $O(n \log n)$
* **Counting Sort (Подсчетом)** — $O(n)$ для HTTP-статусов (диапазон 100–599)
* **Radix Sort (Поразрядная)** — $O(n)$ побайтовая сортировка для IPv4-адресов

## Детекция DDoS-атак

Система обрабатывает 10 000 сетевых логов:
1. **Counting Sort** распределяет запросы по корзинам статусов (100–599). Всплеск кодов 5xx сигнализирует об отказе серверов.
2. **Radix Sort** выполняет 4-проходную побайтовую сортировку IPv4-адресов.
3. Аналитический модуль группирует запросы по IP и вычисляет источники с аномальной концентрацией трафика (потенциальные ботнеты).
